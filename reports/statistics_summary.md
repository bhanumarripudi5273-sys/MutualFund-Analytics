# Statistics Summary

## Project
Mutual Fund Analytics

---

# 1. Mean

Mean is the arithmetic average of all values in a dataset.

Formula:

Mean = Sum of all values / Number of values

Use:
It represents the average investment amount made by investors.

---

# 2. Median

Median is the middle value after arranging the data in ascending order.

Use:
Median helps understand the central value without being affected by extreme investment amounts.

---

# 3. Mode

Mode is the value that occurs most frequently.

Use:
For this dataset, the most common transaction type can be considered the mode.

---

# 4. Standard Deviation

Standard deviation measures how much the data varies from the average.

- Low Standard Deviation → Values are close to the average.
- High Standard Deviation → Values are widely spread.

Use:
It helps understand the variation in investment amounts.

---

# 5. Correlation

Correlation measures the relationship between two numerical variables.

Correlation values range from:

- +1 → Strong Positive Relationship
- 0 → No Relationship
- -1 → Strong Negative Relationship

Use:
Correlation analysis helps identify relationships between investment-related variables.

---

# 6. Probability Basics

Probability measures the likelihood of an event occurring.

Formula:

Probability = Favorable Outcomes / Total Outcomes

Example:

Probability of an investor selecting SIP as the transaction type.

---

# 7. Regression (Introduction)

Regression is a machine learning and statistical technique used to predict continuous numerical values.

Example:

Predicting future investment amounts based on investor characteristics.

Regression helps organizations estimate future business performance using historical data.

---

# Conclusion

Statistical techniques such as Mean, Median, Mode, Standard Deviation, Correlation, Probability, and Regression provide valuable insights into business data. These concepts support decision-making, trend analysis, and predictive analytics in data analysis projects.
